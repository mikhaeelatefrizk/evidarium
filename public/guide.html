Choose where to work.

Hosted workspace

Sign in with ChatGPT to save private projects, search Europe PMC/PubMed/Crossref, store originals, screen sources, record evidence receipts, write notes, and export records.

AI inference and scientific execution are not enabled on the hosted service.

Standalone local edition

The same interface runs on your computer. Connect your eligible ChatGPT plan through OpenAI's official local open-source flow and approve analysis tasks using your own hardware.

Local and hosted projects are separate. Transfer project JSON and original files explicitly.

  1. Install Node.js 22.13+ and Python 3.11+ from their official websites.
  2. Download and extract the local edition ZIP.
  3. Run bash start.sh on macOS/Linux, or ./start-windows.ps1 in Windows PowerShell. Follow your organization's script policy.
  4. Keep the terminal open. The application opens at http://127.0.0.1:4317.
  5. Open the connection panel, authorize on OpenAI's site, and choose an available model.

The launcher creates a local Python virtual environment and installs the pinned base packages. Optional engines and model weights are separate installations. Tokens require an OS credential store. No API key or separate API billing fallback is configured.

From a source to a supported claim.

  1. Define the brief. Save your question, eligibility criteria, and external-search preference. Changes are recorded.
  2. Find and screen. Search Europe PMC, PubMed, or Crossref, inspect returned metadata, and add relevant records. Include/exclude at an explicit stage; exclusions need a reason.
  3. Preserve originals. Upload your files. Stored does not mean extracted. In the local edition, prepare and approve extraction, then use Files → Read text to inspect passages and warnings.
  4. Create a receipt. Open Claims → Record. Enter the claim, choose a saved abstract or extracted file location, paste an exact quotation, and choose supports, contradicts, or context.
  5. Review the interpretation. The server must find the exact passage. A new receipt stays unreviewed until you accept or reject the interpretation.

Model source buttons open the matching project record. A missing record is reported. Finding a source ID or matching a quotation does not establish scientific validity, causality, or study quality.

Chat shortcuts: /search your query opens a real literature search; /note your text saves a note. Other messages use the connected model in the local edition.

Approve real computation.

Choose Run an analysis, select the actual input, and prepare parameters. Activity shows the immutable task and input fingerprint. Approve to execute. Completed results, errors, cancellations, and interrupted runs are different states.

Results from outside Evidarium

Upload externally produced data, code, logs, and reports as original files. Imported project task records retain an external-origin label. Evidarium does not claim it executed or independently reproduced them. Hardware rental and remote job scheduling are not implemented.

Actual ChatGPT authorization.

The local application uses PKCE authorization and validates the returned identity and plan-usage permission. Your OS credential store retains the tokens; the website never receives them. The selected account's current model catalog supplies the available choices, and the selected model is used without silent substitution.

Each request streams through OpenAI's Responses endpoint. Only a completed provider event marks the response complete. Partial text is retained when a request fails, is cancelled, or exceeds its budget. Plan eligibility, model limits, and context limits still apply.

ChatGPT website sign-in, ChatGPT subscription inference, and local execution are separate permissions. The local open-source flow does not automatically authorize hosted inference. One account registration per local data directory is supported; a multi-account picker is not implemented.

Understand the data destinations.

Hosted records use the Site's database and file storage. Local records use your computer. When you use AI chat, selected project text goes to OpenAI. Search queries go to Europe PMC, PubMed, or Crossref; disable external search in Project brief to block both manual and assistant searches. That setting does not disable the model or recall earlier disclosures.

The app includes no analytics SDK. No user data, credentials, or article full text is bundled in the source release. This is not a claim of end-to-end encryption, zero retention, institutional compliance, or a completed security audit.

Export, backup, and recovery

Export JSON for sources, receipts, notes, conversations, task records, and full audit history; CSV for screening. Original file contents are separate downloads. Imported outputs remain externally supplied and imported receipts need review. Stop the local app before backing up its complete data directory at ~/.evidarium. Credentials are in the OS keyring and are not included.

On restart, unfinished runs become interrupted. Incomplete uploads remain removable; automatic resume is not implemented. Do not expose the local port to a network or share the application as a multi-user server.

Visible, practical bounds.

Storage2 GiB per file; 200 files per project; 8 GiB per account. Format storage and format understanding are separate.
ExtractionDefault 300 PDF pages, 10,000 rows/sheet, two million extracted characters. Warnings describe missing coverage.
Model contextUp to 24 recent turns / 48,000 characters, file inventory, and selected passages. Up to 12 BM25 keyword matches; not exhaustive memory.
Search20 records per query. Exploratory retrieval, not a complete systematic review.
ExecutionOne analysis and one chat at a time. Six model rounds; 35-minute worker ceiling; tighter engine/provider limits may apply.
Import2 MiB in the UI; collection limits of 1,000 sources, 100 notes, 500 messages, 100 tasks, 500 receipts, and 1,000 audit events.

Institutional collaboration, automatic cloud/local synchronization, universal audio/video processing, remote hardware rental, a full thesis editor, and journal submission are not implemented. No research outcome is guaranteed.

Mechanism, code, and verification.

The source download includes the full application, schema/migrations, local server, OAuth client, scientific adapters, Docker recipes, tests, architecture, API reference, security boundaries, and third-party notices. Original code is MIT licensed; dependencies and models retain their own terms.

Verification covers account isolation, cross-origin writes, checksummed uploads, source deduplication, screening history, import/export, task approval/failure, exact-passage receipts, search restrictions, bounded extraction, streaming events, and a real worker calculation. Live OAuth and optional heavyweight engines require further validation. Supported browser QA was unavailable in the build environment.

New in 0.2: work from the actual evidence

Search Europe PMC for abstracts and open-access papers. Save a record, then choose Import open-access text. The original XML, retrieval details, license statement, and fingerprint are preserved. Read extracted passages and their coverage warnings in Files.

Search this project finds passages, older conversations, notes, analysis results, and claims. You can also type /find terms. Search covers indexed history rather than only the latest 2,000 messages. It uses keyword ranking, not semantic understanding. The chat view loads 100 messages at a time.

Completed local model answers now include a reference report. It identifies missing records, missing locations, metadata-only citations, and evidence not supplied during that run. A resolving citation does not establish that a claim is true.

Article imports accept up to 6 MiB XML and extract at most 240,000 characters / 2,000 blocks. Figure pixels, equation layout, references, and supplements are not interpreted. Imports are blocked when external search is disabled; previously imported files remain readable.

Verification: 24 JavaScript checks and 9 Python checks passed. A live Europe PMC article import and passage search passed. Live ChatGPT authorization, advanced scientific-engine validation, cross-platform installation, and supported browser QA remain outstanding.
